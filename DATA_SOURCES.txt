Data sources used by the current model pipeline

data_files/ is excluded from this git repository (see .gitignore), since most sources are third-party data that should not be redistributed. This file documents the data files that data_loader.py and the calculations/ modules actually load, so the folder can be reconstructed from public sources. It supplements data_files/README.txt, which documents a wider set of files (including some no longer used) and is kept locally only.

nitrogenrensing_avløp.xlsx
Nitrogen removal efficiency at named major Norwegian wastewater treatment plants (VEAS, Bekkelaget, NRVA, etc.)

Bekkelaget: https://vannforeningen.no/wp-content/uploads/2016/05/04-Eliassen.pdf, supplemented with figures from egenkontrollrapporter (self-monitoring reports) to Statsforvalteren
NRVA: removal rate assumed 70% where figures are missing
